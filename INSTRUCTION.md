# Инструкция по использованию бота Hotline Service

## 1. Описание проекта

**Hotline Service Bot** — это автоматизированная система для сервисной службы, разработанная на Python с использованием библиотеки `aiogram 3.x`. Бот предназначен для приема, обработки и ведения заявок на ремонт и диагностику станков с ЧПУ.

Ключевые возможности:
*   **Прием заявок от клиентов** через пошаговый диалог (FSM).
*   **Распределение ролей**: Клиент, Инженер, Администратор.
*   **Прямой канал связи**: Обеспечение диалога между клиентом и инженером, взявшим заявку в работу.
*   **Администрирование**: Управление списком инженеров и экспорт данных.
*   **Хранение данных**: Вся информация о заявках и инженерах сохраняется в локальной базе данных SQLite.

## 2. Роли пользователей

В системе предусмотрено три уровня доступа:

*   **Клиент** — любой пользователь Telegram, запустивший бота. Может создавать заявки, просматривать FAQ и общаться с назначенным инженером.
*   **Инженер** — зарегистрированный специалист сервисной службы. Может просматривать новые заявки, брать их в работу, общаться с клиентами и закрывать выполненные заявки.
*   **Администратор** — пользователь с полными правами. Управляет списком инженеров, имеет доступ к статистике и может экспортировать базу данных заявок.

## 3. Инструкция для Администратора

Администратор обладает расширенными правами и управляет основной логикой работы сервисной службы.

### 3.1. Назначение нового Администратора

Права администратора не назначаются через команды в боте. Они жестко прописаны в конфигурационном файле для обеспечения безопасности.

1.  **Узнайте свой Telegram ID**. Самый простой способ — написать боту `@userinfobot` и он пришлет ваш ID.
2.  **Откройте файл `.env`**, который находится в корневой папке проекта.
3.  Найдите переменную `ADMIN_IDS`.
4.  Добавьте ваш Telegram ID в список через запятую, без пробелов.
    *Пример:* `ADMIN_IDS=7039700975,123456789`
5.  Сохраните файл и **полностью перезапустите бота** (например, через `start.bat`), чтобы изменения вступили в силу.

### 3.2. Управление инженерами

Администратор может добавлять и удалять инженеров, которые будут получать уведомления о новых заявках.

*   **Добавить инженера**
    Отправьте команду в формате `/add_eng <ID> <Имя>`:
    ```
    /add_eng 123456789 Иван Петров
    ```
    Где `123456789` — это Telegram ID инженера.

*   **Удалить инженера**
    Отправьте команду в формате `/del_eng <ID>`:
    ```
    /del_eng 123456789
    ```

*   **Посмотреть список инженеров**
    Отправьте команду `/list_eng`, и бот пришлет список всех зарегистрированных инженеров с их именами и ID.

### 3.3. Статистика и экспорт данных

*   **Получить статистику**
    Команда `/stats` выводит краткую сводку по заявкам: общее количество, число активных и закрытых.

*   **Экспорт базы заявок**
    Команда `/export` формирует и присылает файл `tickets_report.csv` со всеми заявками из базы данных. Файл содержит полную информацию, включая комментарии к закрытию.

## 4. Инструкция для Инженера

Чтобы стать инженером, попросите администратора добавить ваш Telegram ID в систему.

### 4.1. Получение и прием заявок

*   Когда клиент создает новую заявку, вы получаете уведомление с полной информацией и кнопкой **`✅ Взять в работу`**.
*   Нажав на эту кнопку, вы закрепляете заявку за собой. Клиент получит уведомление, что вы подключились к его проблеме. Сообщение о заявке у других инженеров обновится, показывая, что она уже занята.

### 4.2. Общение с клиентом

*   После того как вы взяли заявку, все ваши сообщения (текст, фото, документы), отправленные в чат с ботом, будут автоматически пересылаться клиенту.
*   **Если у вас несколько активных заявок**, бот перед отправкой вашего сообщения попросит выбрать, какому именно клиенту вы хотите ответить, с помощью кнопок.

### 4.3. Завершение заявки

*   В сообщении с заявкой, которую вы ведете, есть кнопка **`🏁 Завершить заявку`**.
*   При нажатии на нее бот попросит вас отправить **комментарий о проделанной работе**.
*   После отправки комментария заявка будет закрыта. Клиент получит уведомление о закрытии и ваш комментарий.

## 5. Инструкция для Клиента

### 5.1. Начало работы

*   Найдите бота в Telegram и отправьте ему команду `/start`.
*   Появится главное меню с двумя кнопками:
    *   **`🛠 Оставить заявку на сервис ЧПУ`** — для создания новой заявки.
    *   **`❓ Частые вопросы`** — для получения справочной информации.

### 5.2. Создание заявки

1.  Нажмите на кнопку **`🛠 Оставить заявку на сервис ЧПУ`**.
2.  Бот последовательно задаст вам несколько вопросов. Отвечайте на них сообщениями в чате:
    *   Название вашей компании.
    *   Модель станка и стойку ЧПУ.
    *   Подробное описание неисправности.
    *   Ваше имя и контактный телефон.
3.  В любой момент вы можете прервать процесс, нажав на кнопку **`❌ Отмена`**.
4.  После ответа на последний вопрос ваша заявка будет создана и отправлена всем дежурным инженерам.

### 5.3. Общение с инженером

*   Как только один из инженеров возьмет вашу заявку в работу, вы получите уведомление.
*   С этого момента вы можете вести диалог прямо в чате с ботом: отправлять текстовые сообщения, фотографии и документы. Все они будут мгновенно доставлены вашему инженеру.

## 6. Техническая часть (для разработчиков)

### 6.1. Требования

*   Python 3.10+
*   Зависимости, перечисленные в файле `requirements.txt`. Основные: `aiogram==3.x`, `aiosqlite`.

### 6.2. Настройка окружения

1.  Клонируйте репозиторий.
2.  В корневой папке проекта создайте файл `.env` по аналогии с `.env.example` (если он есть) или с нуля.
3.  Заполните файл `.env` необходимыми данными:
    ```env
    # Токен вашего бота, полученный от @BotFather
    BOT_TOKEN=8829473795:AAHTJi883-S7aTQJJ7eoMrB6Peo9hitMkNU
    
    # Список Telegram ID администраторов через запятую
    ADMIN_IDS=7039700975
    
    # Путь к файлу базы данных SQLite
    DB_PATH=hotline_service.db
    ```

### 6.3. Запуск

*   **Для Windows**:
    Просто запустите файл `start.bat`. Он автоматически создаст виртуальное окружение (если его нет), установит зависимости и запустит бота.

*   **Для Linux/macOS (или вручную)**:
    ```bash
    # Создайте и активируйте виртуальное окружение
    python3 -m venv .venv
    source .venv/bin/activate
    
    # Установите зависимости
    pip install -r requirements.txt
    
    # Запустите бота
    python3 -m bot.main
    ```

### 6.4. Важные замечания

*   **Конфликт `getUpdates`**: Лог-сообщение `TelegramConflictError: terminated by other getUpdates request` означает, что вы пытаетесь запустить вторую копию бота с тем же токеном. Убедитесь, что работает только один экземпляр.
*   **База данных**: Файл базы данных SQLite (`hotline_service.db` по умолчанию) будет создан автоматически при первом запуске в директории, указанной в `DB_PATH`.
